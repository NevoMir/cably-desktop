# Ubuntu 24.04 packages needed to build, test and package Cably Desktop on Linux.
# One package per line; '#' comments and blank lines are ignored.  Consumed by
# .github/workflows/linux.yml (grep -vE '^\s*(#|$)' | xargs apt-get install) and kept
# identical to the RUN apt-get install list in cably/linux/Dockerfile.build —
# cably/tests/linux-ci.sh fails when the two drift.
#
# Derived from KiCad 10's top-level find_package() calls plus what the Cably additions and
# the test scripts need: libsecret (Linux secret store), clang (the unit tests are built
# standalone with clang++ like on macOS), xvfb/xauth (launch test), python3/curl/lsof
# (bridge.sh's mock cloud + loopback checks), file/dpkg-dev (packaging).
